================================================================================
PROMPT PROFESSIONNEL - DÉVELOPPEMENT WEB RANGOAPP
Version Web avec Next.js 14+ et Tailwind CSS
================================================================================

CONTEXTE DU PROJET
================================================================================

Créer une application web professionnelle et responsive pour RangoApp, un système 
de gestion multi-boutiques permettant aux entreprises de gérer leurs stocks, 
ventes, factures, clients, fournisseurs et caisse. L'application web doit être 
une réplique fidèle de l'application mobile Android existante, avec une interface 
moderne, intuitive et entièrement responsive.

L'application doit supporter :
- Gestion multi-boutiques (une entreprise peut avoir plusieurs stores)
- Rôles utilisateurs (Admin peut voir toutes les boutiques, User voit sa boutique assignée)
- Authentification JWT via GraphQL
- Opérations CRUD complètes sur tous les modules
- Interface responsive (mobile, tablette, desktop)
- Design moderne et professionnel

================================================================================
ARCHITECTURE TECHNIQUE
================================================================================

STACK TECHNIQUE REQUIS :
------------------------
- Framework: Next.js 14+ (App Router)
- Language: TypeScript (strict mode)
- Styling: Tailwind CSS 3.4+
- UI Components: shadcn/ui ou Radix UI
- GraphQL Client: Apollo Client ou urql
- State Management: Zustand ou React Context + useReducer
- Forms: React Hook Form + Zod validation
- Date Handling: date-fns ou dayjs
- Icons: Lucide React ou Heroicons
- HTTP Client: Axios ou fetch API
- Authentication: NextAuth.js ou custom JWT handling
- File Upload: react-dropzone (si nécessaire)
- Charts: Recharts ou Chart.js (pour les rapports)
- Tables: TanStack Table (React Table v8)
- Notifications: react-hot-toast ou sonner
- Loading States: react-loading-skeleton

DESIGN SYSTEM & UI/UX
================================================================================

COULEURS PRINCIPALES :
----------------------
- Primary: Cyan (#00BCD4) - Actions principales, liens
- Secondary: Yellow (#FFC107) - Accents, highlights
- Success: Green (#4CAF50) - Succès, confirmations
- Error: Red (#F44336) - Erreurs, alertes
- Warning: Orange (#FF9800) - Avertissements
- Background: White (#FFFFFF) / Light Gray (#F5F5F5)
- Text Primary: Dark Gray (#212121)
- Text Secondary: Medium Gray (#757575)
- Border: Light Gray (#E0E0E0)

TYPOGRAPHIE :
-------------
- Font Family: Inter ou System UI (sans-serif)
- Headings: Font-weight 600-700
- Body: Font-weight 400
- Small text: Font-weight 300-400
- Sizes: xs (12px), sm (14px), base (16px), lg (18px), xl (20px), 2xl (24px), 3xl (30px)

ESPACEMENT :
------------
- Utiliser l'échelle Tailwind: 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px
- Padding cards: 16px-24px
- Gap entre éléments: 16px-24px
- Marges sections: 32px-48px

COMPOSANTS UI :
---------------
- Utiliser shadcn/ui comme base
- Tous les composants doivent être accessibles (ARIA)
- Dark mode: Optionnel mais recommandé
- Animations: Subtiles avec Framer Motion (optionnel)
- Loading states: Skeleton loaders pour meilleure UX
- Empty states: Messages et illustrations appropriés

RESPONSIVE BREAKPOINTS :
-------------------------
- Mobile: < 640px (sm)
- Tablet: 640px - 1024px (md, lg)
- Desktop: > 1024px (xl, 2xl)

Layout mobile:
- Sidebar devient un drawer/menu hamburger
- Tables deviennent des cards empilées
- Formulaires en pleine largeur
- Navigation bottom bar (optionnel)

Layout desktop:
- Sidebar fixe à gauche (240px-280px)
- Contenu principal avec max-width 1280px centré
- Header fixe en haut
- Tables avec toutes les colonnes visibles

FONCTIONNALITÉS PRINCIPALES
================================================================================

1. AUTHENTIFICATION
-------------------
Pages:
- /welcome - Page d'accueil (bienvenue)
- /login - Connexion (phone + password)
- /register - Inscription multi-étapes:
  * Étape 1: Informations personnelles (name, phone, password)
  * Étape 2: Création entreprise (name, address, phone, email, description, type, logo, rccm, idNat, idCommerce)
    - Utilise la mutation CreateCompany
  * Étape 3: Création première boutique (name, address, phone, companyId)
    - Utilise la mutation CreateStore

Fonctionnalités:
- Validation des formulaires avec Zod
- Messages d'erreur clairs
- Redirection automatique après connexion
- Gestion du token JWT (localStorage ou httpOnly cookie)
- Refresh token automatique
- Logout avec nettoyage du state

2. DASHBOARD (Page d'accueil)
------------------------------
Route: /dashboard

Contenu:
- Message de bienvenue personnalisé
- Statistiques rapides (cards):
  * Total ventes du jour
  * Produits en stock faible
  * Clients actifs
  * Montant caisse
- Graphiques (optionnel):
  * Ventes des 7 derniers jours
  * Top 5 produits
- Actions rapides:
  * Nouvelle vente
  * Nouveau produit
  * Nouveau client

3. MODULE VENTES
----------------
Routes:
- /ventes - Liste des ventes
- /ventes/new - Créer une nouvelle vente
- /ventes/[id] - Détail d'une vente

Fonctionnalités:
- Liste des ventes avec:
  * Filtres (date, client, montant)
  * Recherche
  * Pagination
  * Tri (date, montant)
- Création vente:
  * Sélection client
  * Ajout produits au panier
  * Calcul automatique (sous-total, TVA, total)
  * Sélection devise (USD, EUR, XAF, XOF, CDF)
  * Date de vente
  * Montant payé et monnaie rendue
- Détail vente:
  * Informations complètes
  * Liste des produits
  * Bouton "Générer facture"
  * Bouton "Imprimer"
- Actions:
  * Supprimer une vente
  * Générer facture depuis vente

4. MODULE STOCK
---------------
Routes:
- /stock - Vue d'ensemble
- /stock/products - Liste des produits
- /stock/products/new - Nouveau produit
- /stock/products/[id] - Détail/Édition produit
- /stock/providers - Liste fournisseurs
- /stock/providers/new - Nouveau fournisseur
- /stock/rapports - Rapports de stock

Fonctionnalités Produits:
- Liste avec:
  * Nom, marque, prix vente, prix achat, stock
  * Filtres (nom, marque, stock faible)
  * Recherche
  * Actions: Modifier, Supprimer
- Création/Édition:
  * Formulaire complet
  * Validation
  * Upload image (optionnel)
- Alertes stock faible

Fonctionnalités Fournisseurs:
- CRUD complet
- Liste avec recherche et filtres

Fonctionnalités Rapports:
- Vue d'ensemble du stock
- Produits en rupture
- Historique des mouvements

5. MODULE CLIENTS
-----------------
Routes:
- /clients - Liste des clients
- /clients/new - Nouveau client
- /clients/[id] - Détail/Édition client

Fonctionnalités:
- Liste avec recherche
- CRUD complet
- Historique des ventes par client (optionnel)

6. MODULE CAISSE
----------------
Routes:
- /caisse - Vue d'ensemble
- /caisse/transactions - Historique transactions
- /caisse/entree - Entrée d'argent
- /caisse/sortie - Sortie d'argent
- /caisse/transfert - Transfert entre caisses

Fonctionnalités:
- Solde actuel de la caisse
- Historique des transactions
- Filtres par type, date
- Création entrée/sortie/transfert
- Rapports de caisse

7. MODULE PARAMÈTRES
--------------------
Routes:
- /settings - Page principale
- /settings/shop - Paramètres boutique/entreprise
- /settings/users - Gestion utilisateurs
- /settings/help - Aide

Fonctionnalités:
- Paramètres boutique:
  * Édition nom, adresse, téléphone, RCCM
  * Sauvegarde avec validation
  * Utilise UpdateCompany et UpdateStore
- Gestion utilisateurs:
  * Liste des utilisateurs
  * Création utilisateur (CreateUser)
  * Actions: Bloquer (BlockUser), Débloquer (UnblockUser), Supprimer (DeleteUser)
  * Gestion des rôles
- Aide:
  * FAQ
  * Guide d'utilisation
  * Contact support
